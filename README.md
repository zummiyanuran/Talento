# BHINNEKA

**Merawat Keberagaman, Menumbuhkan Potensi.**

Human Resource Management & Development System — Komnas Perempuan.

Platform pengelolaan SDM untuk presensi, jadwal kerja, cuti, lembur, pengajuan, persetujuan, dan administrasi pegawai.

## Identitas

BHINNEKA terinspirasi dari Salam Indonesia yang Bhinneka. Identitas visual menggunakan ungu, magenta, biru, hijau dan emas untuk menggambarkan keberagaman dan pertumbuhan bersama.
